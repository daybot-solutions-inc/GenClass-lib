Privacy

Short version: the model runs on your users' devices, decisions never need our servers, and we only use your email to talk to you about GenClass.

The runtime

The GenClass runtime makes every decision in the browser with a local model. It does not need a GenClass account or server to work.

From runtime 0.2.1, the runtime sends anonymous diagnostics by default on public hosts, to help improve the model, and not on local or private hosts (localhost, *.localhost, *.local, *.test, 127.0.0.1, ::1, private IP ranges). By default they contain no text from the page: only a random per-page session id, versions, mode, device class, the app's hostname and id-normalised path, and for each decision the trigger, diagnosis and confidence, action, gate, outcome, latency and counts. The situation text the model read is sent only when the app opts in with telemetry: { include: { situation: true } }; with that on, the redacted situation can include route names with query strings, short error messages and short field values (see TELEMETRY.md). In either setting it never sends typed password, payment or secret values, cookies, headers, request or response bodies or storage contents, and the collector stores no IP address or user agent. Turn it off with GenClass.init({ telemetry: false }), ?genclass=no-telemetry, localStorage genclass.telemetry=off, or Global Privacy Control. Full details are in TELEMETRY.md.

GenClass Cloud

Cloud is not available yet. It is planned to be optional and to receive only data from apps you connect with a publishable project key: aggregate metrics such as counts, categories and timings.

Early-access sign-ups

When you request early access we store your email, company, number of apps and the plan you picked. We use it only to contact you about GenClass, never sell or share it, and delete it on request.
