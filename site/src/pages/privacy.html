Privacy

Short version: the model runs on your users' devices, decisions never need our servers, and we only use your email to talk to you about GenClass.

The runtime

The GenClass runtime makes every decision in the browser with a local model. It does not need a GenClass account or server to work.

The runtime sends anonymous, redacted diagnostics by default to help improve the model: decisions with the redacted situation text the model read, outcomes and counts. It never sends typed password, payment or secret values, cookies, headers, request bodies, storage or query strings, and the collector stores no IP address or user agent. Turn it off with GenClass.init({ telemetry: false }), ?genclass=no-telemetry, or Global Privacy Control. Full details are in TELEMETRY.md.

GenClass Cloud

Cloud is optional and only receives data from apps you connect with a publishable project key: aggregate metrics such as counts, categories and timings.

Early-access sign-ups

When you request early access we store your email, company, number of apps and the plan you picked. We use it only to contact you about GenClass, never sell or share it, and delete it on request.
