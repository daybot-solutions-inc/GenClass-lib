02 / What it catches

Ten failure types. One model. No rules.

These bugs never throw an exception, so error monitors never see them. GenClass watches every request, response and state write, and one model decides what is going on.

Stale responses

An old response lands over newer data, like search results for "pa" under a box that says "paris". GenClass discards it.

Duplicate submits

A double-tap or a retry places the same order twice. GenClass coalesces the repeat into one request.

Race conditions

Two writers race for one field and the wrong one wins. GenClass keeps the newer value.

Failure storms

An endpoint starts failing and the app hammers it. GenClass spots the storm and backs off.

Broken state

It learns rules your data keeps, like a total matching its line items, and flags the moment one breaks.

Slow and flaky calls

Latency far off the learned baseline, or a blip a careful idempotent retry would survive.

04 / Install

Two lines. No account.

Add the runtime and you are protected. Add a project key later if you want the Cloud dashboard. The runtime never depends on the cloud to keep working.

// npm i @genclass/runtime
import { GenClass } from "@genclass/runtime";

GenClass.init();   // that's it
import { GenClass } from "@genclass/runtime";

GenClass.init({
  cloud: { projectKey: "gc_pub_..." },
});

08 / FAQ

Questions

Is GenClass free?

Yes. The runtime is open source under Apache-2.0 and free forever, including in commercial apps, with no usage limits. Cloud and Enterprise are optional paid products for central dashboards, alerts, rollout controls, SSO and audit logs.

Does it need an account or an API key?

No. npm install @genclass/runtime and GenClass.init() is all it takes. A publishable project key is only needed for GenClass Cloud.

Where does the AI model run?

In your users' browsers, inside a Web Worker on WebGPU or WASM. Decisions never depend on a server, so there are no per-inference fees and protection keeps working offline.

Will it break my app?

The default mode only observes and changes nothing. In our real-app sweep, 396 of 396 correct runs were left exactly as they were. ?genclass=off turns it off instantly.
