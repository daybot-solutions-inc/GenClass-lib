Get started with GenClass.

Install the runtime, add one line, and your app is watched by an on-device model. No account and no API key.

Install

GenClass works in any web app that runs in a browser: React, Next.js, Vue, Svelte, Angular or plain HTML.

npm install @genclass/runtime

Or let the CLI detect your stack, show the diff and write it for you:

npx @genclass/runtime init            # observe mode
npx @genclass/runtime init --mode guard
npx @genclass/runtime remove          # undo exactly what init added

No build step? Add one script tag first in <head>:

<script src="https://cdn.jsdelivr.net/npm/@genclass/runtime"
        data-mode="observe" data-devtools="local"></script>

Initialize

Call init() as early as possible, before your app starts making requests:

import { GenClass } from "@genclass/runtime";

GenClass.init();

Prefer zero code? Import the auto entry instead: import "@genclass/runtime/auto"; (or /auto/guard). The model downloads at idle, is cached, and runs in a Web Worker on WebGPU or WASM.

Modes

ModeWhat it does
observeDefault. Reports likely problems with the evidence and never changes app behaviour.
guardActs at the network boundary: discard, defer, coalesce, delay.
healExperimental. Adds retry, serve_cached, hedge, rollback, resync and custom actions.
 
GenClass.init({ mode: "guard" });
Recommended path: ship observe first, read the detections for a week, then turn on guard for the routes where they look right.

Aggressiveness

Once GenClass can act, the profile sets how sure it must be first. balanced is the default.

GenClass.init({ mode: "guard", aggressiveness: "cautious" }); // "cautious" | "balanced" | "eager"

Explain and undo

Every detection and intervention is logged in plain English. rt.explain(id) returns the exact situation the model read, its facts and every answer. Discards and rollbacks return an ActionRecord with undo(), and the devtools overlay lists everything live.

[GenClass] Prevented a stale write: GET /search?q=pa landed after q=paris was shown (stale; discard)

Kill switch

Append ?genclass=off to any URL and nothing is installed. ?genclass=observe|guard|heal overrides the mode for that page. A breaker downgrades the mode automatically after repeated undos.

Self-host the model

Strict Content-Security-Policy or no third-party CDNs? Serve the model from your own origin:

npx @genclass/runtime fetch-model public/genclass-model
npx @genclass/runtime init --model-url /genclass-model/

Privacy

Decisions are made on-device. Anonymous redacted diagnostics are on by default to improve the model; turn them off with GenClass.init({ telemetry: false }) or npx @genclass/runtime init --no-telemetry. See privacy.

Connect GenClass Cloud

Early access. The cloud option below is the proposed API and ships with GenClass Cloud. Request access.
GenClass.init({
  cloud: { projectKey: "gc_pub_..." },   // publishable, metrics-only key
});

The runtime never waits on the cloud. If it is unreachable, protection continues locally.
